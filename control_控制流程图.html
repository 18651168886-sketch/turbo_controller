01｜总览：谁判断状态，谁计算指令

COMMRead_ISM（输入处理）整理测量与指令；ESM（发动机状态管理）决定工况；CLM（控制规律管理）计算执行指令；FPM（故障处理）提供保护信息；ControlOut（执行输出接口）整理最终输出。故障保护也分布在 CLM 内部，并非全部由一个模块完成。

模块学习重点
ESM/Flags（状态转换条件）把控制指令、转速、排温、空速、高度及工况完成反馈组合成转换条件。
ESM/StateTransition/StateTranslation（状态机）七个工况之间如何转换；默认进入 Origin（原位）。
CLM（控制规律管理）按状态选择原位、起动、闭环、手动、停车等控制分支。
CLM/ControlOut_Manage（执行命令统一管理）Accelerator_Manage（油泵给定管理）与 SWO_Manage（开关输出管理）分别处理两类执行量。
ControlOut（执行输出接口）输出18项信号，包括阀、电机、点火、引气、发动机状态、复位请求及转速。

02｜七种工况与两套编码

图中七条支路是按状态互斥选择的工况分支，不是依次执行的七个步骤。各工况得到油泵给定及阀、电机等命令后，进入执行命令统一管理。

EngineState（发动机工况状态码）为0～6：原位0、地面起动1、闭环2、手动3、停车4、空中起动5、丙烷起动6。Start_OpenLoop（起动开环流程）中的 Flag_EngineState（内部阶段反馈）还会出现2、4、15：分别用于完成/停车请求等判断；不能因为数字相同就当成同一变量。

04｜地面起动：从A阶段一直追到申请闭环

模型位置：control/CLM/Start/Start_OpenLoop

阶段主要执行动作推进条件异常/学习要点
A（预转）电机开通为NPump0；主/副阀周期30、开通30且使能。CNT_Start_A ≥ 50次（1000/20）；然后记录夹限后的油压参考。约1秒计数阈值，实际切换按先判断后加一执行。
B（升至点火转速）满足Nc≥1000时，点火=1，油泵给定=5000，保存T4。Nc≥1000 → C。否则CNT_Start_B≥300次：内部阶段标志=4，电机开通=0。
C（点火后过渡）一级条件满足后：主阀关闭且使能0，给定=m1。二级条件满足后：电机开通按(100−NPump0)/(T×1000/20)增加。一级：C计数>150次 或 POil−Origin_POil≥50 或 Flag_IntoC。二级：C1计数≥t×50 或 Nc≥6000 或 Flag_IntoC。电机开通达到100 → D。Flag_IntoC用于记忆已进入加速支路；不要把每个判断当成独立状态。
D（确认升速）保持前面已建立的执行量，继续检查转速。Nc>n1 → E。D计数>300次：关点火、给定0、内部阶段标志15。
E（供油爬升）给定=(m2−m1)/(n2−n1)×Nc+(m1×n2−m2×n1)/(n2−n1)。Nc>13000时另有关电机/点火动作。Nc>20000 → F；进入F时电机开通0、使能0、点火0、给定=m3。POil>700的支路中，压力高计数>100次会断油并置15；E计数>1500次同样置15。计数何时清零以源码为准，不将它概括为连续2秒。
F（主副阀过渡）Nc>28000 或 F计数≥1000次后，关闭副阀；EValve计数>50次开主阀并给m4。EValve计数>150次后，内部阶段标志置2；反馈给ESM后转闭环。末端另有电机关闭保持逻辑：Nc>13000 或已允许关闭时，计数>4后保持开通0。

09｜故障保护：短时保持、10秒锁存与开环降级

模型位置：control/FPM/Subsystem

逻辑当前模型行为
转速原始故障Nc_Flag_Locking（转速信号锁定） 或 Ncdot_Flag_Locking（变化率锁定）。
锁存计时输入只在EngineState=闭环 且 原始转速故障时送入锁存计时器；Time_ms=10000，Ts_ms=20。
锁存判据计数严格大于10000/20=500后置锁存；Flag_Lock（内部锁存记忆）为真后继续保持，不是故障消失立即解除。
锁存前Flag_NcFailure = 原始故障 且 非锁存；闭环故障处理中先保持上一周期给定。
锁存后按装订转速与导航高度估算开环给定，再做上下限与每次10的步进处理。
估算表0高度层：转速[40000,62000]→给定[2028,7342]；5高度层→[1317,4148]；第三层→[702,1929]。高度先除以1000，函数内分段插值。
估算滤波的特殊点先夹到Acc_Min/Acc_Max；与上一给定的差的绝对值<20时，输出仍是上一给定；否则按方向±10。不能简单说成“直接输出估算值”。
超转FPM中Nc_Filter>62000产生OverSpeed_Protect（超转保护标志）；不能把该标志的产生本身等同于ControlOut直接断油。
复位恢复Flag_ECUReset_Use为真时，Hold_2000ms产生约2秒恢复窗口；窗口有效时统一给定使用ECUReset_Acclerator（复位恢复油泵给定），覆盖普通选择结果。
恢复数据保存闭环状态下Hold_4000ms在计数>4000/20后置保存请求并清计数，形成周期请求；不是只保存一次。
估算函数的第三高度层分段写法与高度越界处理具有具体实现：u2<5时在前两条曲线间插值，否则在后两条曲线间；u2<0用第一条曲线，u2>11用第三条曲线。不要自行将第三层命名为固定10或11公里标定点；直接查看函数表达式。
